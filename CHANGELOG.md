# Changelog

The release notes for `qaflow_protocol`, `qaflow_agent` and `qaflow`. The
three packages share one version and are released together.

## 0.1.4 - 2026-11-11

- `qaflow`: the README and example explain subflows (`runFlow`, `.qa/subflows`, `env`, `when`,
  inline `commands`).
- The docs have one copy of each user guide: the architecture guide's command reference and
  troubleshooting chapters are now `docs/commands.md` and `docs/troubleshooting.md`, and its
  integration and remote-host chapters point to the user guides.

## 0.1.3 - 2026-11-10

- `qaflow_agent`: a fuller README (the separate `lib/main_qa.dart` entrypoint,
  shared setup code, making widgets findable, resetting state, a first flow,
  troubleshooting), an example with both entrypoints, and API docs for
  `QaAgent`.
- The packages are now developed in this repository.

## 0.1.2 - 2026-11-10

- Adds API documentation and links the published source on GitHub.

## 0.1.1 - 2026-11-10

- Adds homepage and issue tracker links.

## 0.1.0

- Initial public release. Early: APIs may change.
